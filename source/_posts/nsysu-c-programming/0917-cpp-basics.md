## 一支程式的骨架

```cpp
#include <iostream>   // ① 前置處理：引入函式庫的宣告
using namespace std;  // ② 命名空間：之後不用一直寫 std::

int main() {          // ③ 程式進入點
    // 你的程式從這裡開始
    return 0;         // ④ 回傳 0 給作業系統＝正常結束
}
```

這支程式可以編譯、可以執行，但**畫面上不會有任何東西**——因為它什麼事都沒做。

第 ② 行的 `std` 是標準函式庫用來裝自己所有名字的一個盒子，這種盒子叫**命名空間（namespace）**；`cout` 的全名其實是 `std::cout`、`cin` 是 `std::cin`（`::` 讀作「某某裡面的」）。`using namespace std;` 等於先跟編譯器說「以下看到不認得的名字，去 `std` 這個盒子裡找」，所以才能省略前面的 `std::`。不寫會怎樣你在 09/10 的示範 ③ 看過了：`error: 'cout' was not declared in this scope`。盒子本身怎麼做出來是 11/26 的主題，現在照抄就好。

`//` 註解、`{ }` 區塊、分號這三條規則〈環境設置〉和 09/10 都講過了，這裡只補兩點：

- **分號跟換行無關**，一個敘述可以拆成好幾行（Q2 的 `cout` 就是），只要最後有分號就好。
- 本文之後大量用 `//` 標示「這一行會印出什麼」，而且**很多程式碼區塊是片段**，只寫出要討論的那幾行。想自己編譯來玩，就把它們貼進上面骨架 `main` 的 `{ }` 裡（用到 `cout` 就要有 `#include <iostream>` 和 `using namespace std;`）；有寫 `#include` 和 `int main()` 的區塊才是可以直接編譯的完整程式。

## 變數與型別

### 識別字（identifier）命名規則

- 只能由**英文字母、數字、底線** `_` 組成，且**不能以數字開頭**。
- **大小寫有別**：`Total`、`total`、`TOTAL` 是三個不同的變數。
- 不能使用**保留字**：`int`、`class`、`return`、`for`、`if`、`new`、`delete`……
- 變數與函式命名寫 `totalScore` 或 `total_score` 都可以，但**整份程式挑一種用到底**，改考卷的人會看風格。（類別、常數的命名慣例等用到的時候再說。）

### 基本型別

| 型別 | 典型大小 | 說明 | 寫起來長這樣 |
| --- | --- | --- | --- |
| `int` | 4 bytes | 整數，約 $\pm 2.1 \times 10^9$ | `int n = 42;` |
| `double` | 8 bytes | 浮點數（**預設用這個**），約 15 位有效數字 | `double x = 3.14;` |
| `char` | 1 byte | 一個字元，實際存的是 ASCII 碼 | `char c = 'A';` |
| `bool` | 1 byte | 只有 `true` / `false` 兩種值，這種值叫**布林值**，09/24 的 `if` 會大量用到 | `bool ok = true;` |
| `string` | 不定 | 字串，長度自動調整，需 `#include <string>` | `string s = "Yilin";` |

另外還有 `long long`（裝得下更大的整數）、`unsigned int`（不能是負數）、`short`（更省空間）、`float`（精度比 `double` 差），這學期幾乎用不到，知道有這些東西就好。

寫「典型大小」是因為實際大小由編譯器與平台決定，想自己量就在程式裡寫 `cout << sizeof(int);`——`sizeof(型別)` 算出該型別在這台機器上佔幾個 byte，也可以寫 `sizeof(變數名)`；我這台印出的是 4 和 8。

`<climits>` 則先幫你定義好 `INT_MAX` / `INT_MIN` 兩個常數，代表 `int` 裝得下的最大與最小值（2147483647 與 -2147483648）。超過範圍不會報錯，值會**繞回去**：`int x = INT_MAX; x = x + 1;` 之後 `x` 變成 -2147483648，這叫**溢位（overflow）**，筆試很愛考（嚴格說它屬於後面〈未定義行為〉那節的狀況，只是一般電腦上都這樣繞）。要用它們就得多寫一行 `#include <climits>`——**用到哪個函式庫的東西，就 `#include` 誰**，忘了會得到 `error: 'INT_MAX' was not declared in this scope`。

### 宣告與初始化

`int age = 18;` 這一行拆開來是三件事：型別 `int` ＋ 名字 `age` ＋ 初值 `18`。

- **宣告**＝跟編譯器登記「我要一個叫 `age` 的 `int` 變數」；**初始化**＝宣告的同時就給它第一個值。
- `=` 唸作**賦值**，意思是「把右邊算出來的值放進左邊的變數」，跟數學的等號不一樣。所以 `sum = sum + 10;` 讀作「把 `sum` 現在的值加 10，再存回 `sum`」，是合法而且很常見的寫法。

```cpp
int age = 18;               // 宣告同時初始化（建議）
double pi = 3.14159;
char grade = 'A';           // 單引號是字元
bool passed = true;
string name = "Yilin";      // 雙引號是字串；用 string 記得 #include <string>

int a, b, c;                // 一次宣告多個；三個都還沒有值，用之前一定要先賦值或 cin >>（見下方雷區①）
int x{5};                   // C++11 寫法，等同 int x = 5;
                            // 這裡的 { } 不是區塊，而是另一種「給初值」的寫法——同一組符號看位置決定意思
                            // 好處：int y{3.99}; 會直接編譯錯誤，擋掉「不小心把小數塞進整數」
```

> **雷區 ①：未初始化的變數**
> ```cpp
> int sum;            // 只宣告、沒給初值 → 裡面是上一個程式留下的垃圾
> sum = sum + 10;     // 拿垃圾值去加，結果當然還是垃圾
> cout << sum;        // 每次執行可能印出不同的數字
> ```
> C++ **不會**幫區域變數自動歸零。累加器一定要 `int sum = 0;`。
> `-Wall` 只抓得到最單純的情況，值一旦繞過幾層就未必抓得到——別靠編譯器，宣告就給初值。

### `const` 具名常數

```cpp
const double PI = 3.14159265358979;
const int MAX_SIZE = 100;
// PI = 3.14;   // 編譯錯誤：assignment of read-only variable
```

`const` 表示「這個變數給了初值之後就不准再改」。好處是**改一個地方就全改**、**編譯器會擋住誤改**、**程式自我說明**（看到 `MAX_SIZE` 比看到 `100` 清楚）。課本與課程都建議用 `const` 而非 `#define`。

命名慣例：常數習慣**全部大寫、字間用底線**（`PI`、`MAX_SIZE`），一眼就能跟普通變數分開；這不算違反前面「命名風格挑一種用到底」，那條講的是變數與函式。`<climits>` 的 `INT_MAX` 就是照這個慣例取名的。

### 字面值與跳脫序列

**字面值**（literal）就是直接寫在程式裡的固定值，編譯器依它的長相決定型別：

```cpp
42        // int
3.14      // double
'A'       // char（單引號，一個字元）
"Hello"   // 字串（雙引號）
```

**記住 `2` 是 int、`2.0` 是 double**——待會的整數除法陷阱就是從這裡來的。（兩個這學期用不到、但看到不要慌的寫法：數字後面加 `L`、`u`、`f` 可指定成 `long`／`unsigned`／`float`；字串前面加 `R` 寫成 `R"(C:\Users\yilin)"`，括號中間原封不動、不做下面的跳脫。）

常用跳脫序列：

| 寫法 | 意義 |
| --- | --- |
| `\n` | 換行 |
| `\t` | Tab |
| `\\` | 反斜線本身 |
| `\"` | 雙引號 |
| `\'` | 單引號 |
| `\0` | 空字元（字串結尾標記，Ch9 會用到） |

## 型別轉換

把一種型別的值放進另一種型別的變數，編譯器會自動幫你轉，這叫**隱式轉換**：

```cpp
#include <iostream>
using namespace std;

int main() {
    int    i = 3.99;    // 小數部分被「截斷」，不是四捨五入
    double d = 5;       // 5 變成 5.0
    char   c = 65;      // 65 是 'A' 的 ASCII 碼
    int    n = 'A';
    bool   b = 42;      // 非 0 皆為 true
    cout << i << ' ' << d << ' ' << c << ' ' << n << ' ' << b << '\n';
    return 0;
}
```

輸出：

```text
3 5 A 65 1
```

三個要注意的地方：

- 電腦裡沒有「字母」，`char` 存的是一個小整數，再依一張叫 **ASCII** 的對照表顯示成字元：`'A'` 是 65、`'a'` 是 97、`'0'` 是 48。所以 `char c = 65;` 印出 `A`，`int n = 'A';` 得到 65。
- `double d = 5;` 裡面確實是 5.0，但 `cout` 預設不顯示沒意義的小數，所以看到 `5`。
- **`bool` 印出來是 `1` 和 `0`**，不是 `true` / `false`。筆試的「看程式答輸出」很愛考。
- 順帶回收前面的伏筆：`int i = 3.99;` 沒事、`int y{3.99};` 卻編譯錯誤，差別就在 `{ }` 初始化會擋掉「會掉資料」的轉換，`=` 不會。這也是建議用 `{ }` 的唯一理由。

`double → int` 會**損失精度**。如果要自己動手、明白寫出「我就是要轉成這個型別」，叫**顯式轉換（cast，強制轉型）**：

```cpp
double d = 3.99;
int i = static_cast<int>(d);   // 現代 C++ 寫法（推薦）
int j = (int)d;                // C 風格，課本也用，考試兩種都可
```

- `static_cast<想要的型別>(要轉的東西)`：角括號裡寫目標型別，小括號裡寫來源。這裡的 `< >` 跟 `#include <iostream>` 的角括號完全沒關係（之後的 `vector<int>` 也是這種用法）。
- `(型別)值` 是 C 留下來的舊寫法，效果一樣，但比較難搜尋、也比較容易誤用。

## 輸入輸出：`cin` 與 `cout`

```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b;
    cout << "請輸入兩個整數：";
    cin >> a >> b;
    cout << "和 = " << a + b << endl;
    return 0;
}
```

在終端機輸入 `3 5` 後，畫面長這樣：

```text
請輸入兩個整數：3 5
和 = 8
```

- `cout << x`：把 `x` 送到標準輸出，`<<` 可以一直串接。
- `cin >> x`：從標準輸入讀一個值。**會自動跳過前置的空白與換行**，讀到下一個空白為止。`>>` 跟 `<<` 一樣可以串接，`cin >> a >> b;` 是先讀一個值放進 `a`、再讀下一個放進 `b`，所以鍵盤打 `3 5`（中間空白或換行都可以）會得到 `a = 3`、`b = 5`。
- `endl` = 換行 + 把輸出立刻送出；`'\n'` 只換行。差別在於 `cout` 為了效率不會每印一個字就送一次螢幕，而是先堆在**緩衝區**累積一批再送。日常用 `'\n'` 就好，輸出量大時才看得出差。（另外還有 `cerr`，**標準錯誤輸出**，不緩衝、專門印錯誤訊息，12/03 講串流時會再遇到。）

**格式化輸出**（需要 `#include <iomanip>`）：

```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    double x = 3.14159265;
    cout << fixed << setprecision(2) << x << '\n';           // 固定兩位小數
    cout << setw(10) << 42 << "|\n";                         // 靠右對齊寬度 10
    cout << left << setw(10) << 42 << "|\n";                 // 靠左對齊
    cout << setfill('0') << right << setw(5) << 42 << '\n';  // 補位字元改成 0
    return 0;
}
```

輸出（結尾的 `|` 是我故意印出來標示欄位右界的）：

```text
3.14
        42|
42        |
00042
```

- `setw(10)`、`setprecision(2)` 這種「名字 + 小括號 + 值」的形狀叫**呼叫函式**，括號裡是你交給它的參數，換個值就換個效果（函式的正式說明在 09/24）；`fixed`、`left`、`right` 則是沒有括號的光禿名字。這些東西都只是**調整 `cout` 的設定**、不是要印出來的內容，送進去畫面上不會多任何字——所以可以像 Q5 解答那樣，單獨寫一行 `cout << fixed << setprecision(1);` 先把格式設定好，後面再印資料。
- `fixed` + `setprecision(n)`：固定小數點後 `n` 位，**這是實驗課題目最常要求的格式**；少寫 `fixed` 的話，`n` 會變成**有效位數**而不是小數位數。`setfill(c)` 則是換掉補位字元（預設空白）。
- `setw(n)` **只對下一個輸出有效**，印完就恢復；其他設定（`fixed`、`setprecision`、`left` / `right`、`setfill`）設一次就一直有效——所以上面第四行要補寫 `right`，把第三行的 `left` 改回來。

## 算術運算與整數除法陷阱

先說三個之後會一直出現的名詞：**運算子**（operator）是做運算的符號；**運算元**（operand）是被運算的東西（`7 / 2` 裡的 `7` 和 `2`）；**運算式**（expression）是運算子與運算元組成、**算得出一個值**的一串東西（`7 / 2`、`a + b * 2`）。

C++ 的算術運算子有五個：`+`（加）、`-`（減）、`*`（乘）、`/`（除）、`%`（取餘數）。乘除的優先順序比加減高，跟數學一樣，不確定就加括號。`%` 只能用在**整數**，`5.5 % 2` 直接編譯錯誤。

```cpp
cout << 7 / 2 << '\n';           // 3    整數 ÷ 整數 = 整數（無條件捨去）
cout << 7 % 2 << '\n';           // 1    取餘數
cout << 7 / 2.0 << '\n';         // 3.5  只要一邊是浮點，結果就是浮點
cout << (double)7 / 2 << '\n';   // 3.5
cout << -7 / 2 << '\n';          // -3   C++11 起向 0 取整
cout << -7 % 2 << '\n';          // -1   餘數與被除數同號
```

> **雷區 ②：整數除法**
> ```cpp
> int a = 5;
> double b = a / 2;      // b = 2.0，不是 2.5！
> ```
> `a / 2` 兩邊都是 `int`，先算出整數 2，才轉成 `double`。正確寫法：`double b = a / 2.0;` 或 `double b = static_cast<double>(a) / 2;`。
> **平均分數算錯**幾乎都是這個原因，是實驗課最常見的扣分點。

### 複合指定運算子

`sum += 5;` 就是 `sum = sum + 5;` 的簡寫——「把自己更新成運算後的結果」：

```cpp
int sum = 0;
sum += 5;    // 等同 sum = sum + 5;  → sum 變 5
sum *= 4;    // 等同 sum = sum * 4;  → sum 變 20
sum %= 3;    // 等同 sum = sum % 3;  → sum 變 2
```

`-=` 與 `/=` 也一樣。作業裡會很常看到，本週練習題 Q4、Q5 的解答就用了 `%=` 和 `+=`。

### `++` 與 `--`

`i++` 與 `++i` 都是把 `i` 加 1（等同 `i = i + 1`，也等同 `i += 1`）；`i--` 與 `--i` 則是減 1。差別只在**這個運算式本身算出來的值**是變動前還是變動後：

```cpp
int i = 5;
cout << i++ << '\n';   // 印出 5，之後 i 變 6（後置：先用值，再加）
cout << ++i << '\n';   // i 先變 7，印出 7（前置：先加，再用值）

int j = 5;
cout << j-- << '\n';   // 印出 5，之後 j 變 4（後置）
cout << --j << '\n';   // j 先變 3，印出 3（前置）
```

單獨寫成一行 `i++;` 時前置後置沒有差別，09/24 的 `for` 迴圈最常這樣用。

### 未定義行為（UB）

**未定義行為**（undefined behavior，常簡稱 UB）是這學期最重要的名詞之一：代表 C++ 標準**沒有規定**這種寫法該產生什麼結果，所以編譯器想怎麼做都可以——可能看起來正常、可能當掉、也可能換台電腦就變另一個答案。之後講陣列越界、指標的時候還會一直遇到。最典型的一種是在同一個運算式裡改同一個變數：

> **雷區 ③：同一個運算式裡改同一個變數**
> ```cpp
> int i = 1;
> int x = i++ + i++;    // 結果未定義，不同編譯器可能給不同答案
> ```
> 不要寫這種程式。筆試若出現，答案通常是「undefined behavior」。

## 程式風格

除了 `//`，還可以用 `/* ... */` 包住跨很多行的註解。筆試會看程式可讀性，實驗課助教檢查時也會看，三個基本要求：**縮排一致（一層 4 個空格或 1 個 Tab，別混用）**、**變數名有意義**、**關鍵步驟有註解**。

## 本節重點回顧

- **宣告變數時就給初值**，C++ 不會幫你歸零；`=` 是「把右邊存進左邊」，不是數學等號。
- **整數除以整數還是整數**：`7 / 2` 得到 3。要浮點結果，至少一邊要是浮點（`7 / 2.0`）。
- `x += 3` 是 `x = x + 3` 的簡寫，`x++` 是 `x += 1` 的再簡寫；前置後置差在「運算式的值」是變動前還是變動後。
- 小數位數用 `fixed << setprecision(n)`（會一直生效）；欄寬用 `setw(n)`（**只影響下一個輸出**）。
- **未定義行為**＝標準沒規定該怎麼做，結果無法預期，不是「這樣寫也會動」。

## 本週練習題

> 全部題目都用 `g++ -Wall -Wextra -std=c++17` 編譯，確認**零警告**。

**Q1. BMI 計算**
讀入身高（公分，浮點數）與體重（公斤，浮點數），輸出 BMI 到小數點後兩位。

$$\text{BMI} = \frac{\text{體重(kg)}}{\text{身高(m)}^2}$$

```text
輸入： 175.5 68.2
輸出： BMI = 22.14
```

<details>
<summary><b>參考解答</b></summary>

```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    double cm, kg;
    cin >> cm >> kg;
    double m = cm / 100.0;          // 注意 100.0 而非 100
    double bmi = kg / (m * m);
    cout << "BMI = " << fixed << setprecision(2) << bmi << '\n';
    return 0;
}
```

</details>

**Q2. 秒數轉時分秒**
讀入一個非負整數 `n`（秒），輸出格式為 `hh:mm:ss`，不足兩位補 0。

```text
輸入： 3725
輸出： 01:02:05
```

<details>
<summary><b>參考解答</b></summary>

```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    int n;
    cin >> n;
    int h = n / 3600;
    int m = (n % 3600) / 60;
    int s = n % 60;
    cout << setfill('0')
         << setw(2) << h << ':'
         << setw(2) << m << ':'
         << setw(2) << s << '\n';
    return 0;
}
```

這個 `cout` 拆成四行寫，但只有最後才有分號——因為它是**一個**敘述。`setfill('0')` 設一次就一直有效，`setw(2)` 則要對**每一個**輸出各寫一次。

</details>

**Q3. 數字拆解**
讀入一個三位數正整數，分別輸出它的百位、十位、個位數字，以及三個數字的和。

```text
輸入： 472
輸出：
4 7 2
sum = 13
```

<details>
<summary><b>參考解答</b></summary>

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    int h = n / 100;
    int t = n / 10 % 10;
    int u = n % 10;
    cout << h << ' ' << t << ' ' << u << '\n';
    cout << "sum = " << h + t + u << '\n';
    return 0;
}
```

`n / 10 % 10` 的運算順序是由左到右（`/` 與 `%` 同優先級），先除再取餘。

</details>

> **以下兩題會碰到「迴圈」與「陣列」**，是 09/24 與 10/08 才正式教的東西。Q4 用本週的 `/` 和 `%=` 就寫得出來（解答第一版）；Q5 非用迴圈不可，當成**純預習題**，09/24 之後再回來做。先給兩個最小夠用的讀法：
>
> - `for (int i = 0; i < 6; i++)` 讀作「`i` 從 0 開始，只要 `i < 6` 就做一次大括號裡的事，每做完一次把 `i` 加 1」。小括號裡那兩個分號是 `for` 的固定格式、不是敘述結尾，所以**這一行行尾不加分號**。其中 `i < 6`、Q5 的 `c <= b` 是**比較**，算出 `true` 或 `false`，跟 `cout <<` 的兩個小於號不是同一件事；`< > <= >= == !=` 這組運算子 09/24 會完整介紹。
> - `int COINS[6]` 是「一次開六個 `int` 排成一列」，這六格叫 `COINS[0]`、`COINS[1]`……`COINS[5]`（**從 0 開始數**），`= {500, 100, 50, 10, 5, 1}` 依序把初值填進這六格。方括號裡的數字在宣告時是「幾格」、使用時是「第幾格」，是兩件事。

**Q4. 找零錢**
讀入一個整數金額（元），用 500、100、50、10、5、1 元由大到小找零，輸出每種各幾張／幾個。

```text
輸入： 1268
輸出：
500: 2
100: 2
50: 1
10: 1
5: 1
1: 3
```

<details>
<summary><b>參考解答</b></summary>

**第一版：本週就寫得出來**（只用到 `/` 和 `%=`，同一組動作重複六次）

```cpp
#include <iostream>
using namespace std;

int main() {
    int money;
    cin >> money;
    cout << "500: " << money / 500 << '\n';
    money %= 500;               // 等同 money = money % 500;
    cout << "100: " << money / 100 << '\n';
    money %= 100;
    cout << "50: " << money / 50 << '\n';
    money %= 50;
    cout << "10: " << money / 10 << '\n';
    money %= 10;
    cout << "5: " << money / 5 << '\n';
    money %= 5;
    cout << "1: " << money << '\n';
    return 0;
}
```

每一輪都是「除出張數、把餘額留給下一種面額」，最後剩下的就是 1 元的個數。

**第二版：學完陣列與迴圈（10/08）之後的寫法**，現在先看個樣子

```cpp
#include <iostream>
using namespace std;

int main() {
    int money;
    cin >> money;
    const int COINS[6] = {500, 100, 50, 10, 5, 1};
    for (int i = 0; i < 6; i++) {
        cout << COINS[i] << ": " << money / COINS[i] << '\n';
        money %= COINS[i];      // 等同 money = money % COINS[i];
    }
    return 0;
}
```

兩版輸出一模一樣，但第二版只要改 `COINS` 那一行就能換一套幣值——這就是陣列加迴圈的價值。

</details>

**Q5. 溫度轉換表**（純預習題，09/24 學完迴圈再回來做）
讀入起始攝氏溫度 `a`、結束溫度 `b`、間隔 `d`（皆為整數），輸出從 `a` 到 `b`（含）每隔 `d` 度的攝氏與華氏對照，華氏取小數點後一位。

$$F = C \times \frac{9}{5} + 32$$

```text
輸入： 0 100 25
輸出：
0C = 32.0F
25C = 77.0F
50C = 122.0F
75C = 167.0F
100C = 212.0F
```

<details>
<summary><b>參考解答</b></summary>

```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    int a, b, d;
    cin >> a >> b >> d;
    cout << fixed << setprecision(1);
    for (int c = a; c <= b; c += d) {    // c += d 等同 c = c + d;
        double f = c * 9.0 / 5.0 + 32;   // 9.0 / 5.0，不是 9 / 5！
        cout << c << "C = " << f << "F\n";
    }
    return 0;
}
```

`c * 9 / 5 + 32` 看起來像「先乘後除所以安全」，其實不是：`c = 1` 時先算 `1 * 9 = 9`，再算 `9 / 5` 仍是整數除法得 1，印出 `33.0`（正解 `33.8`）。只有 `c` 剛好是 5 的倍數才會碰巧對，而這題的範例輸入 0、25、50、75、100 全是 5 的倍數，所以「測範例都對」反而最危險。

</details>
