第一週主課是課程介紹，實驗課則會帶你把 VirtualBox / Ubuntu / g++ / Makefile 弄起來。這一篇除了列出該做的事，也先把幾個「開學第一週最容易誤會的事」講清楚。

## 這門課到底在教什麼

課名寫「C 程式設計」，但**整學期教的是 C++**。這不是筆誤，是課名沿用了很久以前的版本沒改。

兩者的關係大致是：C++ 是在 C 的基礎上長出來的，**C 能寫的東西 C++ 幾乎都能寫**，但 C++ 多了一整套 C 沒有的東西——最重要的就是**類別（class）**，也就是「把資料和操作資料的函式綁在一起」的能力。這學期後半（10 月中之後）幾乎都在講這件事。

實務上的差別，第一天就會遇到：

| 做同一件事 | C 的寫法 | C++ 的寫法（這門課用這個） |
| --- | --- | --- |
| 印東西到螢幕 | `printf("%d\n", x);` | `cout << x << '\n';` |
| 從鍵盤讀資料 | `scanf("%d", &x);` | `cin >> x;` |
| 字串 | `char s[100];` | `string s;` |
| 動態要記憶體 | `malloc` / `free` | `new` / `delete` |

**所以上網找資料時請搜 C++ 的關鍵字**（`cout`、`class`、`vector`）。搜到 `printf`、`scanf`、`malloc` 的教學雖然也能跑，但跟這門課的作業要求不一樣，愈看愈亂。

## 整學期的地圖

如果覺得進度表看起來很雜，可以先記住它其實只有三大塊：

```text
① 基本功（9 月）      變數、判斷、迴圈、函式、陣列
        ↓  把一堆散落的變數和函式收納起來
② 物件（10–11 月）    struct / class、建構子、vector、運算子重載
        ↓  搞懂資料實際存在記憶體的哪裡
③ 進階（11–12 月）    指標與動態記憶體、分離編譯、檔案 I/O、繼承
```

前八週的東西後面會一直用到，**基本功沒打穩，後面會非常痛苦**——這也是為什麼期中考只考到第 ② 塊的前半。

## 第一週實際要做的事

**務必做完的三件事：**

1. [〈環境設置〉](/2026/09/09/nsysu-c-programming/setup/)整段從頭到尾走一次，包含 Guest Additions 與快照。
2. 能靠自己在 Terminal 從空白目錄產出、編譯、執行一支 `HelloWorld.cpp`，**不看筆記**。
3. 能靠自己寫出[〈Makefile：從零到模組化〉](/2026/09/09/nsysu-c-programming/setup/#makefile從零到模組化)那份 Makefile，**不複製貼上**。

沒做完這三件事，之後每一週的實驗課都會被環境問題拖住，而實驗課的分數是**當場檢查**給的，拖不起。

**自我檢測**：在 Terminal 完成下面這串，中間不查資料：

```bash
mkdir -p ~/week01/B1130xxxxx && cd ~/week01/B1130xxxxx
nano Q1.cpp          # 寫一支印出自己學號的程式
nano Makefile        # 寫模組化 Makefile
make && ./Q1
make clean && ls     # 確認執行檔被清乾淨
cd .. && zip -r B1130xxxxx.zip B1130xxxxx/
```

全部一次做完不卡關，你的環境就準備好了。

## 第一次寫程式一定會遇到的三個狀況

**① 編譯錯誤（compile error）不是壞事，是常態**

新手常以為「編譯過不了 = 我不會寫程式」。實際上就算寫了很多年，編譯錯誤也是每天都在發生的事。重點是學會讀錯誤訊息：

```text
Q1.cpp:5:15: error: expected ';' before '}' token
```

這串的意思是：**`Q1.cpp` 這個檔、第 5 行、第 15 個字元附近，少了一個分號**。錯誤訊息前面永遠是「檔名:行號:欄號」，先照著行號跳過去看就對了。

**② 錯誤訊息一次噴幾十行時，只看第一個**

C++ 的錯誤常常會連鎖爆炸——一個少打的分號可以引發二十行紅字。**只有第一個是真的**，修掉它再重新編譯，後面通常會一起消失。

**③ 程式編過了不代表對**

編譯器只檢查「文法有沒有錯」，不檢查「你想做的事對不對」。把加法寫成減法，編譯器一句話都不會說。所以**每寫完一題都要實際跑幾組測資**，這個習慣從第一週就要養成。

## 本週重點回顧

- 課名是 C，教的是 **C++**；找資料要用 C++ 的關鍵字。
- 整學期＝基本功 → 物件 → 指標與進階，前面沒穩後面會很痛苦。
- 這週唯一的任務是**把環境弄到「不用想就能編譯執行」的程度**。
- 錯誤訊息的格式是「檔名:行號:欄號: error: 說明」，**先修第一個**。
